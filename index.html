Apps

Install any .ipa

SuperStore lets you install any app you want, alongside the many available in verified sources. Your own certificate does the signing, and apps are re-signed in the background before the development window runs out.

⬇

Any .ipa, any source

Install apps from your own sources or from the listings already built in.

✓

On-device signing

Signed with your personal certificate over a loopback tunnel — no AltServer.

↻

Anisette failover

If one Anisette server is down the next is tried, and sign-in errors get explained.

Open Source

Free, forever

SuperStore is fully open source and built by its community. Everything it stands on is public too — you can read every line, and freely contribute to the project on GitHub.
