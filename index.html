Features

Install any .ipa

SuperStore signs apps with your personal development certificate and installs them over a loopback tunnel, so anything you already sideload works here too.

⬇

Any .ipa, any source

Drop in apps from your own sources, or from the store listings already built in.

✓

On-device signing

Your own certificate does the work, and apps are re-signed before the 7-day window expires.

↻

Anisette failover

If one Anisette server is down, the next one is tried — and sign-in errors are explained in plain language.

Setup

Three steps, one time

Sign and install it

FAQ

Questions

Is SuperStore free?

Yes. It is open source under the AGPL-3.0, and there is nothing to pay for beyond your own Apple ID.

Do I need a computer?

Only for the first install. After that the app signs and refreshes itself over Wi-Fi.

How is this different from SideStore?

SuperStore is a fork. It adds Anisette server failover, turns Apple's cryptic sign-in codes into explanations you can act on, and carries its own branding. Everything else — sources, refresh, backups — comes from SideStore.

Can I install it today?

There is no signed release yet. You can build it from source, or use the unsigned build produced by CI and sign it yourself.

Is this affiliated with SideStore or AltStore?

No. It is an independent fork, built on their AGPL-3.0 work, with the original notices kept.
