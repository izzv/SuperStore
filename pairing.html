Getting a pairing file

SuperStore talks to iOS device services through a pairing file: the record your computer creates when it pairs with your iPhone over USB. iOS only writes it while the phone is unlocked and you have tapped Trust, and it is tied to that one phone.

Windows: let the setup helper make it

  1. Plug the iPhone into the PC and unlock it.
  2. Open SuperStore Setup and press Pair.
  3. When the iPhone asks Trust This Computer?, tap Trust and enter the passcode.
  4. Leave the phone on the home screen, unlocked, until the window says the pairing file was copied into SuperStore.

The helper writes pairingFile.plist and copies it into SuperStore's Documents folder, so the app finds it on its next launch without you picking anything.

Pick the file yourself

On the pairing screen in SuperStore, tap Select Pairing File and choose the file your computer produced. SuperStore reads any of these:

  • pairingFile.plist — the lockdown pairing record, also called PairingFile_Lockdown.plist.
  • *.mobiledevicepairing — what jitterbugpair writes on macOS or Linux.
  • PairingFile_RemoteRP.plist — the remote pairing record, if you already use one.

Anything that only carries private_key, public_key and identifier, or has no UDID, is not a pairing record and will be rejected with “Missing UDID”.

If it is rejected

  • The phone was locked, or Trust was never tapped: unlock it, plug it in again, tap Trust, and make a fresh file.
  • You picked a different phone's record: a pairing file only works with the UDID it was made for.
  • The file came from an app that trimmed it: make it again with the helper, jitterbugpair, or your own tooling and keep the whole plist.

You can add or replace the pairing file later under Settings → Advanced → Pairing File.
